# Delevry DZ — server release 1.1.0

The authoritative deployment package for this release is `delevry-dz-rebuild-1.1.0.zip`.

The working/deployment source is the PostgreSQL rebuild supplied from the server package, not the older MySQL-oriented files that existed on main.

This GitHub branch is an archival development mirror for the release. Deployment remains manual by uploading the ZIP to the server.

Release focus:
- professional logistics operations UI
- Arabic RTL responsive layout
- authenticated HTTP-only session
- fixed demo login flow
- shipment creation tied to the authenticated operator
- refreshed dashboard, tracking and shipment form
- local logistics visual asset
